DataMate

Repository: Front-end Back-end
My Capstone group project for my final year in college. DataMate is meant to help MSMEs (Micro Small Medium Enterprises) transition from using logbooks and spreadsheets to a secure database and manage their data efficiently. This is done by allowing the user to upload their spreadsheet to the webapp and it will map the data and create a database in the webapp.
